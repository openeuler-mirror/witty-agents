## 1. 设计原则

| 原则 | 落地手段 |
|---|---|
| 层次化，不挤一屏 | 三级拆分：导航层（选功能区）→ Tab/子导航层（拆同类功能）→ 卡片/分区层（拆页内区块）；单屏只承载一个主任务 |
| 空间功能明确 | 每页统一骨架：`PageHeader（面包屑+标题+主操作区）→ 工具/筛选区 → 主内容区 →（可选）侧信息区`；区块间用卡片与标题分隔，职责单一 |
| 内容长短自适应 | 按内容形态选机制：分页 / 虚拟滚动 / 折叠 / Tab 拆分（见第 6 章决策表） |
| 滚动隔离 | 内容区独立滚动（body 不滚）；页面内日志、阶段列表、动态流各自独立滚动，互不联动 |
| AI 内联不占框 | Agent 能力以能力点形态附着于所属功能区，即用即走（见第 10 章） |

## 3. 全局布局骨架

- **顶栏**：高 56px，白底带下边框（对齐参考仓库：无渐变/无 emoji，Logo 为主色文字）；主导航当前项主色加粗；面包屑以竖线分隔随页切换（概览页随 #members/#settings 锚点联动文案）；通知（文字+未读徽标）与用户菜单（含「视角」角色切换、修改密码/登出）；Esc 关闭全部下拉/抽屉/弹窗。
- **侧边栏**：宽 200px，白底下边框；激活项为实心主色药丸；仅项目内出现；<1024 隐藏。
- **内容区**：max-width 1400 居中；左右 padding 32px；卡片间距 16px；区块锚点卡 `scroll-margin-top:76px` + `html{scroll-behavior:smooth}`（锚点跳转不被顶栏遮挡、平滑滚动）。
- **PageHeader 统一规范**：`H1 标题 + 状态徽标（可选） + 右侧主操作按钮组（≤3 个）`（面包屑在顶栏，不在页内）。

## 6. 长内容自适应机制决策表

| 内容形态 | 机制 | 组件方案 |
|---|---|---|
| 构建日志（万行持续追加） | 虚拟滚动 + 自动吸底 + 滚离停止跟随 + 全量下载 | el-table-v2 / 自研虚拟列表 |

| 表单参数多（14 项构建参数） | 分组折叠：基本区平铺 4 项 + 「高级选项」折叠 + 「发布选项」折叠（权限显隐） | el-collapse + el-drawer |
| 页面功能多（项目内/Agent 详情） | Tab/侧边栏拆分 | el-tabs / 侧边栏二级导航 |
| Stage 阶段列表 + 日志 | 双栏独立滚动（滚动隔离） | flex 布局 + 各自 overflow |
| 详情字段多（Agent 元信息） | 两栏 el-descriptions + 可折叠区块 | el-descriptions |
| 动态/通知流 | el-timeline + 「加载更多」按钮 | — |
| 仪表盘卡片 | CSS Grid 自适应换行 | 断点见第 7 章 |
| 图例条目过多（饼图） | K=6 项截断 + 「…其余 N 项」chip，悬停浮层展示全量明细（内部滚动） | LegendK |

| 图表 Agent 过多 | 卡头多选筛选下拉（全选/清空/计数/名称·id 检索）+ Top 5/8/全部（超出聚合「其他」） | ChartFilter |
| 弹窗/抽屉层级 | 遮罩仅响应自身空白处点击（内容点击不冒泡误关）；Esc 全局关闭 | overlay click 判定 |

## 7. 响应式与间距规范

- 断点：`≥1280` 双栏/图表双列全量展示；`1024~1280` 双栏降为单栏、隐藏顶栏面包屑；`<1024` 侧边栏隐藏、导航收窄、「视角」标签隐藏，触发构建 Drawer 近全屏（94vw）；
- 间距系统：8px 基准（区块间 16px，卡片内 16/18px）；
- 字号：正文 14、辅助 12、H1 20、区块标题 14.5；表格行高 48/表头 40（对齐参考仓库密度）；
- 内容区 max-width 1400，居中。

## 8. 角色 × 视图差异矩阵

### 8.1 四层差异机制

| 差异层 | 机制 | 典型示例 |
|---|---|---|
| 菜单层 | 路由级显隐（前端路由守卫） | 顶栏「管理」仅系统管理员；项目内「成员管理」「设置」仅项目管理员+ |
| 区块层 | 组件级不渲染 | 触发构建 Drawer「发布选项」折叠区开发成员不渲染；Agent 禁用构建开关（admin-only）与非管理员状态标签（admin-else）互补渲染；构建详情发布 Stage 参数明细对 developer 隐藏 |
| 按钮层 | disabled + tooltip | 取消/重跑：非触发者且非 admin 置灰，提示"仅触发者或项目管理员可操作" |
| 数据层 | 接口按权限过滤 | 工作台仅聚合有权项目；审计项目管理员只见本项目；开发成员不可导出 |

兜底：前端隐藏仅为体验层，所有 API 后端二次鉴权（RBAC-05），越权 403 + 审计。

## 9. LogViewer 日志规范

### 9.1 分级着色

| 匹配 | 颜色语义 |
|---|---|
| `ERROR` / `FAILED` / `✗` / `exit 1` | 红（行背景淡红） |
| `WARN` | 橙 |
| `PASSED` / `SUCCESS` / `OK` / `PASS` | 绿 |
| Jenkins 时间戳前缀 `[HH:mm:ss]` | 灰、弱化 |

### 9.2 关键内容高亮规则表

| 内容 | 正则（示意） | 样式 |
|---|---|---|
| prerelease 版本号 | `\d+\.\d+\.\d+-ci\.(aarch64\|x86-64)\.\d+` | 蓝底 chip |
| SHA-256 | `[0-9a-f]{64}` | 等宽 + 紫；悬停显示前 8/后 8 位缩写 |
| dist-tag | `\b(x86-test\|arm-test\|latest)\b` | latest 加删除线警示；架构 tag 为徽标 |
| npm 包名 | `(@openeuler/[\w.-]+\|witty-agent-[\w.-]+)` | 蓝色 chip |
| Agent id | 注册 id 词表匹配（随 agents.json 同步） | 青色 |
| commit hash | `\b[0-9a-f]{7,40}\b` | 等宽 + 灰蓝 |
| URL | `https?://\S+` | 链接色、可点击（新窗口） |
| 阶段起止 | `stage\('(.+?)'\)` / Jenkins 阶段分隔行 | 渲染为分隔标题条（加粗、卡片背景），锚点与 Stage 视图联动 |

实现备注：高亮规则预编译，在虚拟滚动行渲染时按行应用，避免全量日志逐行正则；搜索命中叠加黄色背景。

### 9.3 交互

- **错误导航条**：`⬆/⬇ 错误(N)` 跳至上/下一错误行并居中；错误计数徽标；
- 搜索框命中高亮 + 命中计数；回车跳下一个；
- 自动跟随开关：新日志到达时若用户滚离底部则暂停跟随，点击「⬇ 底部」恢复；
- 行号悬停显示复制图标，点击复制整行。

## 10. 嵌入式 Agent 能力点设计

### 10.1 组件规范

**InlineAgentPanel（内联诊断条/建议条）**

- 挂载位置：所属区块顶部或底部（日志区顶部、门禁区底部、趋势卡内）；
- 展开即插入内容流，**不弹窗、不跳页、不新建框架**；右上角收起按钮；
- 内容结构：结论摘要 → 依据（可回链日志行/Stage/配置项）→ 建议动作（按钮或链接）；
- 标识：左上角 AI 徽标；底部「有用/无用」反馈；进行中构建标注「阶段性结论」。

**AgentIconAction（行级/卡片级入口）**

- 主色药丸形 AI 图标（纯文字「AI …」，无 emoji），跟随宿主元素（失败 Stage 卡、门禁清单项、配置项角标、详情抽屉前缀区块）；
- 点击就地展开气泡或小卡片（popover），展示解释/建议；
- 高危建议在 popover 内展示 diff 确认卡。

### 10.2 能力点分布表

### 10.3 护栏交互（对应 COP-08）

| 风险级 | 交互形态 |
|---|---|
| 低危（触发构建/重跑/取消/读取分析） | Agent 直接执行 → **toast 回执**（含撤销入口，如"取消刚触发的构建"） |
| 高危（改 Jenkins 配置/参数默认值/agents.json/启用·禁用 Agent 构建） | **页内 diff 确认卡**：旧值→新值逐项对比 + [应用][放弃]；配置已被他人修改时提示"基于过期版本"，可刷新重取 |
| 发布类（PUBLISH=true/dist-tag/回滚） | 仅建议卡：给出操作路径与「去发布」链接，**无执行按钮**，用户手动到发布流程执行 |

- 权限联动：能力点显隐跟随宿主区块（第 8 章矩阵）；Agent 提议越权操作时，前端不渲染执行入口，仅保留建议文本；
- 审计标记：AI 发起操作统一标识"用户 × Agent"，审计日志页提供筛选项。
