witty-agent-factor 前端原型

面向 witty-agents 生态（可安装到 opencode/witty 的 Agent 包）的管理前端。所有数据为 mock，但严格对齐上游仓库事实：4 个真实 Agent、根 Jenkinsfile 的 11 个构建阶段与 14 个参数、prerelease + 架构 dist-tag 发布门禁。所有页面可跳转、所有按钮均有响应。

LG登录页独立布局；登录成功跳转工作台 DB工作台统计卡片 + 双栏 + AI 趋势解读（嵌入式能力点） OV项目概览Agent 健康度 + 动态 + 设置区（AI 建议 diff 确认卡） AGAgent 管理4 个真实 Agent 卡片；启停/删除受角色控制 BL构建列表筛选 + 真分页 + AI 汇总条 + 触发构建抽屉（14 参数） BD构建详情11 阶段 Stage 视图 + 日志高亮/错误导航 + AI 诊断条 RL发布详情门禁清单 + 失败项 AI 解释 + 回滚（仅管理员） US用户管理系统管理员页面；启停需二次确认 AU审计日志支持「用户 × Agent」标记筛选，行点击看详情
角色差异化视图
顶栏右侧「视角」切换 项目管理员 / 开发成员 / 只读访客。切到开发成员：触发构建抽屉中的「发布选项」区块消失；切到只读访客：触发/重跑/删除等操作按钮全部隐藏——对应设计文档第 8 章四层差异矩阵。
日志可读性
构建详情页：ERROR/WARN/PASS 分级着色；版本号（0.10.5-ci.aarch64.0）、SHA-256、dist-tag、npm 包名、Agent id、commit、URL 识别高亮；上一/下一错误导航；搜索回车高亮命中；行号点击复制；「模拟追加」体验自动跟随。
嵌入式 Agent 能力点
AI 能力不占独立框架，附着于功能区就地展开：日志区「AI 分析」诊断条、构建表单「AI 推荐」、构建列表「AI 汇总」、门禁失败项「AI 解释」、设置区「AI 建议」（高危 diff 确认卡，人审后才应用）。护栏：低危自动 / 高危人审 / 发布仅建议。
长内容自适应
列表分页（构建/审计/用户）、日志虚拟化滚动、14 参数分三段折叠（基本/高级/发布）、项目内功能侧边栏拆分、阶段列表与日志双栏滚动隔离。
mock 数据对齐上游仓库事实
